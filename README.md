# KIET Bootcamp 3 — Python backend with Bottle + SQLite

Material, stage code and data for the 21–22 September 2026 bootcamp. Everything works offline once cloned.

- Setup (once, online): follow https://aikaryashala.com/kiet/bootcamp-03/setup.html
- Check the machine: `python3 check_env.py`
- Read the material: `cd docs && python3 -m http.server 8000` then open http://localhost:8000
