Day 2 · Omarchy customization

Make Omarchy yours

Day 2, on the Omarchy laptop. Task 1: your name in the wordmark's block letters on the screensaver. Task 2: your photo on the boot and login screens.

~/.config/omarchy/branding/screensaver.txt

What you are changing

Omarchy's screensaver is a text file run through random terminal effects: ASCII art in ~/.config/omarchy/branding/screensaver.txt, one copy per monitor, until you touch a key. Out of the box that file holds the Omarchy logo. Put your own name there and the screensaver is yours. This page draws the name in the same block letters as the Omarchy wordmark and hands you the file.

Everything here is for the Omarchy laptop, not the Ubuntu VM. The commands are Omarchy 4.0's; if you are on an older release and a menu entry is missing, the commands in the last section still work.

Task 1 · your name on the screensaver

Type your name. The big preview is the Omarchy Font; the panel under it is the exact text that goes into the file: each block character is two half-rows of the letter bitmap, which is how the wordmark itself is drawn. Letters, digits and punctuation all work. Press Enter or the button to download.

YOUR NAME

screensaver.txt 0 bytes








Put it in place


    

  1. The browser saved the file to ~/Downloads. Move it over the logo. There is no backup to make: Restore Default below brings the logo back any time.
    

    terminal
    

    $ mv ~/Downloads/screensaver.txt ~/.config/omarchy/branding/screensaver.txt
    

    2. 

  2. See it now. This forces the screensaver up even if the idle one is switched off. Any key or mouse movement exits it.
    

    terminal
    

    $ omarchy-launch-screensaver force
    

    Or from the keyboard: Super+Esc opens the Omarchy menu at System; pick Screensaver. Left alone, it comes up by itself after two and a half minutes idle.
    3. 







Without the browser


Two ways that never leave the machine.
The menu. Super+Space opens the Omarchy menu. Style › Screensaver › Edit Text opens screensaver.txt in your editor; save and quit, and the screensaver fires up so you see the result. Set From Image converts a png or svg to ASCII instead. Restore Default puts the Omarchy logo back.
The command. omarchy ascii draws text in the same FIGlet font the wordmark uses, Delta Corps Priest 1. That font has letters and spaces only; digits and punctuation are dropped and named on stderr, which is the one reason to prefer the generator above.


terminal


$ omarchy ascii "Ravi Teja" > ~/.config/omarchy/branding/screensaver.txt$ omarchy-launch-screensaver force


The same three menu entries, and omarchy branding screensaver reset, exist for the About screen: the file is ~/.config/omarchy/branding/about.txt and the window that pops up is the one from About in the Omarchy menu.






Task 2 · your photo on the boot and login screens


The screen you see while Omarchy boots, and the login screen after it, share one logo and two
colours. Omarchy lets you swap all three with omarchy plymouth. Pick a photo of yourself,
turn it into a small PNG, preview the result without touching the boot setup, then apply it. This one needs
your password, because the boot screen lives in system folders.
    

  1. Pick a photo. Any jpg or png: from your phone over USB, from the camera app, or from ~/Pictures. Copy it somewhere short. The examples use ~/Pictures/me.jpg.
    

    terminal
    

    $ ls ~/Picturesme.jpg
    

    2. 

  2. Make a small PNG. The boot logo must be a PNG, and it sits on a 1920×1080 canvas, so 400 pixels wide is plenty. ImageMagick is already on Omarchy: magick resizes and converts in one go.
    

    terminal
    

    $ magick ~/Pictures/me.jpg -resize 400x400 ~/Pictures/me.png$ magick identify ~/Pictures/me.png/home/kiet/Pictures/me.png PNG 400x300 400x300+0+0 8-bit sRGB 187452B 0.000u 0:00.000
    

    The second line shows the size it came out at. A photo works as is; a logo with a transparent background looks best, but that is a job for another day.
    3. 

  3. Preview. Two colours and the photo: background first, then text, both as #RRGGBB. This renders the boot screen into a PNG and opens it in the image viewer. Nothing is changed yet. Press q to close the viewer.
    

    terminal
    

    $ omarchy plymouth preview '#1d2021' '#ebdbb2' ~/Pictures/me.png ~/Pictures/boot-preview.png
    

    Change the two colours until it looks right. Dark background, light text is the safe pair; the two above are the Gruvbox theme's.
    4. 

  4. Apply it. Same two colours, same photo, no output file. It asks for your password once, rebuilds the Plymouth theme and gives the SDDM login screen the same look.
    

    terminal
    

    $ omarchy plymouth set '#1d2021' '#ebdbb2' ~/Pictures/me.png[sudo] password for kiet:
    

    5. 

  5. See it. The login screen shows it as soon as you log out: Super+Space, then System › Logout. The boot screen shows it on the next restart.
    

    terminal
    

    $ omarchy plymouth current
    

    6. 

  6. Back to normal, whenever you like. This restores the Omarchy logo and colours for both screens, and asks for your password again.
    

    terminal
    

    $ omarchy plymouth reset
    

    7.
