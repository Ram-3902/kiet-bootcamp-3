# Demo videos

One short screen recording per stage, played from the Demo video section of that stage's page. The files are **not in git** — they are handed out on the day from a USB stick or the LAN share and copied into this folder:

    cp /media/usb/kiet-bootcamp-3-videos/*.mp4 ~/kiet-bootcamp-3/docs/videos/

Until a file is here, the page shows "Demo video not available yet — follow the written steps below." in its place. Nothing else on the page depends on the video.

Format: MP4 (H.264 + AAC), 1366×768 or larger, screen only, no webcam. Terminal font at least 16 px so it reads on a projector. Narration optional. Each video follows the Task section of its page step for step, in the same order, with the same commands — a student should be able to pause the video and find the same line on the page.
