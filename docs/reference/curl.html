Flags

-i
show the response headers (status line first) above the body
-X POST
use the POST method instead of GET
-H "Content-Type: application/json"
tell the server the body is JSON
-d '{"number": 17}'
the body. Single quotes outside so the double quotes inside survive the shell
-s
silent: no progress bar when you pipe or save the output

Quoting and spaces

Quote any URL with & or ? in it. Unquoted, the shell reads & as "run in background" and the second parameter never reaches curl.

Spaces are not allowed in a URL. Write + instead: college=Narayana+Junior+College. The server turns it back into a space. The browser does the same thing for you, spelling it %20.
