What it is

JSON is text that looks like a Python dict or list. It is how programs hand each other data over HTTP. Keys are strings in double quotes. Values are strings, numbers, true/false, null, lists [ ], or objects { }.

json
{"count": 2, "students": [  {"student_name": "Ravi Teja Kanchi", "inter_college": "Sri Chaitanya Junior College", "inter_city": "Visakhapatnam"},  {"student_name": "Sai Kiran Bommu", "inter_college": "Sri Chaitanya Junior College", "inter_city": "Visakhapatnam"}]}

dumps and loads

python
import json answer = {"number": 17, "is_prime": True}text = json.dumps(answer)          # dict -> text:  {"number": 17, "is_prime": true}print(text) data = json.loads('{"number": 4}') # text -> dictprint(data["number"] + 1)          # 5

In Bottle you rarely call these yourself: return a dict from a route and Bottle does dumps; read request.json and Bottle has done loads.
