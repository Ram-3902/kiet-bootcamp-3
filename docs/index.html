KIET Bootcamp 3 · 21 September 2026, three sessions · AI Karyashala

HTTP in → SQL in the middle → JSON out

What this is

One day, three sessions. You arrive knowing C. You leave with a Python program that answers HTTP requests with JSON read from a SQLite database, and a web page that uses it. Every stage is one new idea, one task, one self-check, one quiz. Everything on this site and in ~/kiet-bootcamp-3 works with the network off. Day 2 is not on this site: team presentations, then Omarchy customization.

Before you start

Before the bootcamp, on a machine with internet: run the setup from aikaryashala.com/kiet/bootcamp-03/setup.html. It installs git, curl and sqlite3, clones this repository to ~/kiet-bootcamp-3, and runs check_env.py. On the day, run the check again, then start this site:

terminal
$ python3 ~/kiet-bootcamp-3/check_env.py…Ready. Start the material site with:    cd ~/kiet-bootcamp-3/docs && python3 -m http.server 8000$ cd ~/kiet-bootcamp-3/docs && python3 -m http.server 8000Serving HTTP on 0.0.0.0 port 8000 (http://0.0.0.0:8000/) ...

Then open http://localhost:8000. That is this page, served from your own machine.
