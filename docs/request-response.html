The four crossings

The same trip as a table. Two of the crossings are HTTP (1 and 4), two are function calls inside the server (2 and 3). The stages of Day 1 are exactly these four, one at a time.

the four crossings
#from → towhat crossesyou see it in
1client → serverGET /students?college=Narayana+Junior+College HTTP/1.1curl -v, or the Network tab (Stage 8)
2server → SQLiteSELECT … WHERE inter_college = ? with the valuethe sqlite3 shell, typed by hand (Stage 1)
3SQLite → servera list of tuples: [('Lakshmi Prasanna Gudla', 'Narayana Junior College', 'Vijayawada'), …]print(rows) in Stage 2
4server → clientstatus line, headers, blank line, JSON bodycurl -i (Stage 3), the browser (Stage 7)
